ComputePool 设备算力聚合

Mac 编排 · iPhone / iPad Worker · 可拆分任务加速（非 OS CPU 融合）

检测中…

诚实说明：本工具是局域网任务编排器，把可拆分作业（含图片缩放压缩）分片到 Mac 本机协程 + 手机 / 平板 Worker。 不是透明的系统 CPU / GPU 融合，也不是越狱或系统级加速。适合批处理图片与演示哈希；不会劫持任意 Mac App，普通软件也不会自动变快。
