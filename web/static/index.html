诚实说明：本工具是局域网任务编排器，把可拆分的 CPU 作业分片到 Mac 本机协程 + 手机 / 平板 Worker。 不是透明的系统 CPU / GPU 融合，也不是越狱或系统级加速。适合演示哈希类批处理；普通 App 不会自动变快。
